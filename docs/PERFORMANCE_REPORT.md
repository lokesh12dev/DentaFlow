## Frontend performance

### Bundle
- **JavaScript bundle:** Generated by Metro (Expo), no manual split configuration
- **Web bundle:** Generated via `expo export --platform web` → `dist/`
- **Font loading:** Zero (system fonts) — no FOUT/FOIT
- **Icon loading:** Zero (code-based SVG via Lucide)

### Rendering
- **Lists:** FlashList virtualization for 4 list usages (appointments, patients, tasks, invoices)
- **Re-renders:** TanStack Query with selective subscriptions; Zustand with selector-based subscriptions
- **Images:** Not applicable (no image assets in operational screens)
- **Animations:** react-native-reanimated 4.5.1 on worklet thread

### Memory
- **Local storage:** expo-sqlite with SQLCipher for offline queue
- **Cache:** TanStack Query with 5-minute stale time, garbage collection after 10 minutes
